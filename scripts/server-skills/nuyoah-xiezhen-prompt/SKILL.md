# nuyoah-xiezhen-prompt

## 目标

把写真意图编译成可直接使用的中文 Prompt；当用户明确要“换个人拍同一套写真”并要求生成时，把参考组还原成可执行的摄影方案，在 Codex Image 中生成指定数量的新照片并完成质量检查与可追溯交付。Eagle 只在当前环境可用时作为附加归档，不是完成任务的前提。

## 入口判断

先选择一种模式：

- 用户提供一组写真参考并表达“照这套拍、换个人拍一套、像去同一家店拍、复刻这套写真企划”等意图时，进入**摄影方案复拍**。读取 [摄影方案复拍工作流](references/production-reshoot.md)；只有用户明确要求生图才执行完整生成闭环。
- 用户说“系列母版、一整套系列、系列规划、固定格式”时，输出系列母版。
- 用户只说“变体、同系列、创作变体、仿拍扩展”，但没有表达完整摄影企划复拍意图时，输出同系列变体关键词链。
- 用户说“完整、详细、精准控制、复刻 Prompt”时，输出详细提示词。
- 用户说“抽卡、网页端、大量生成、短关键词、开盲盒”时，输出 6–8 行抽卡关键词。
- 用户给图片并要求拆解时，输出图片关键词；组图先提取共同视觉 DNA，再列单张差异。用户明确“只拆解、不生图”时不得进入生成闭环。
- 用户给出 `主题：`、人物类型、`关键词：` 三段骨架时，直接按 [提示词逻辑与模板](references/prompt-logic.md) 的三段式规则编译，不依赖包外模板。
- 用户说“文化视觉溯源、文化元素、往外扩展灵感”时，只根据当前可见证据区分事实、强关联和灵感联想；需要外部史实或来源时先真实检索，不依赖私有知识库方法。

普通提示词、变体、拆解与模板规则读取 [提示词逻辑与模板](references/prompt-logic.md)。维护或回归验收本 Skill 时，同时读取 `evals/skin_reflection_cases.json` 与 `evals/production_reshoot_cases.json`。

## 参考图职责

1. 人物图承担身份还是摄影参考，必须先分清。用户另外提供人物形象图但没有说明用途时，只问一次：它是要保持同一位人物，还是只借人物气质？
2. 人物身份参考只回答“她是谁”，保持主要五官辨识度；目标写真接管妆容、发型、服装、场景、道具、光线和情绪。
3. 写真方案参考只回答“这套写真怎样被拍出来”，不承担人物身份。Prompt 必须正向写入：`本张重新生成一位「【原创女性类型】」类型的成年原创女性，不要继承写真参考图中人物的脸。`
4. 没有人物身份图时，根据写真类型自动替换 `【原创女性类型】`，以人物好看、动作自然和画面成立为优先；不检查组内是否为同一张脸，也不增加生成脸与写真参考人物逐一比较的验收层。

## 共享原则

1. 先判断照片为什么成立，再写细节。光线必须写清来源、方向、在人身与环境中的落点和成像结果；更换机位时，光源、遮挡物与环境反射固定在世界空间中，先重建新视角下的受光关系，再编译 Prompt。
2. 风格写成可观察的成像机制，不用“高级、氛围感、电影感”代替白平衡、曝光、反差、高光、锐度、噪点、压缩和景深。
3. 穿搭只写服装，饰品放入道具；场景与道具分开。
4. 默认人物为成年年轻女性，强调成年后的青春、灵动和生命力；不写未成年或儿童化表达。
5. 有人物身份图时把身份与表情分开控制；身份图只提供稳定五官锚点，本张表情由目标拍摄中的具体人物事件决定，不默认继承身份图的中性眼神和嘴角状态。
6. 场景复杂度服从参考图的画面信息层级；先区分主体清晰区、主导大形、次级细节和低细节留白，不因场景元素多就让背景每一层都清楚。
7. 摄影方案复拍的每一轮都从原始人物图、原始写真参考和本轮重新编译的完整 Prompt 开始；上一轮生成图只用于诊断问题。除非用户明确要求编辑上一张图，不把任何生成图作为新一轮视觉输入，也不在旧 Prompt 上追加补丁式修图指令。
8. 新一轮结果直接对照原始写真参考判断；“比上一轮更有风格”只表示相对改善，不能替代原作保真、结构检查和用户验收。
9. 原作若依赖欠曝、失焦、堵黑和偶发抓拍，必须启动去商业抛光层：把连续暖色轮廓光、皮革折面塑形、稳定脸部焦点、正面回填和英雄式构图改写为原作支持的物理结果；精致 editorial 原作不套用这条降质规则。
10. 皮肤质感必须区分纹理与反射；近景、直闪或高光妆面要按景别控制底妆反射和高光范围。
11. 图片拆解只写可见事实；不确定内容标为“疑似”，不编造品牌、摄影师、器材或历史来源。
12. 用户没有明确要求生成时，只交付 Prompt 或拆解结果，不产生图片、Eagle 资产或项目记录。
13. 默认不添加任何署名或水印。只有用户明确要求时，才加入用户指定的署名文字；不得默认使用 `nuyoah` 或替用户决定署名内容。

## 输出

- 普通模式直接交付用户触发的 Prompt 或拆解结果，不输出内部分析模块。
- 摄影方案复拍必须在对话中交付简短摄影方案摘要、实际图片、每张完整 Prompt、参考职责、质量状态与追溯记录。Eagle 可用且归档成功时再附 Eagle ID；不可用或归档失败不影响上述核心交付。
- 默认中文，仅保留模型更易理解的摄影英文词。

## 环境兼容

在有本地项目规则的工作区中，先读取当地 `AGENTS.md` 和适用的生图方法；项目规则可以补充归档与记录要求，但不得把署名或 Eagle 变成跨环境默认前提。环境提供图片生成工具且用户明确要求生图时，才执行真实生成；没有图片生成工具时，明确停在 Prompt 与摄影方案交付层，不得声称已经出图。检测到 `nuyoah-codex-image-to-eagle` 且 Eagle 可用时才执行归档；未安装、未连接、同步失败或用户不使用 Eagle 时，继续在对话中完成全部核心交付。
