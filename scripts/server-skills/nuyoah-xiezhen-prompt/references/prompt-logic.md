# nuyoah 写真提示词逻辑

## 一句话

写真提示词不是许愿“好看的美女”，而是写清一场拍摄为什么成立。这个技能有五个方向：生成一整套系列母版；生成同系列变体关键词链；生成单条详细控制型中文写真提示词；生成网页端大量抽卡用的短关键词提示词；或根据单张图片 / 一组系列图反向拆解可复用关键词。系列母版和详细提示词使用模块化拍摄小抄；同系列变体先在内部完成模块化拆解，真正提交生图时必须编译为一段有序、紧凑、无模块标题的中文关键词链。

## 提示词生成原则

### 1. 写真探索先人物，场景最后

自动化探索或系列扩展时，不要把“换场景”当成主要创新点，也不要先用服装、道具或视觉色调倒推妆容。默认排序是：

```text
妆容母体 -> 同系妆容变体 -> 发型 / 服饰搭配 -> 道具元素 -> 构图 -> 镜头角度 -> 动作表情 -> 光线质感 -> 场景
```

写细节前，先选一个主成立点：

- 妆容成立：水蜜桃氧气感、清透奶油裸妆、白开水妆、青苹果氧气妆、玫瑰水光妆、红茶千金妆、冷欲猫系妆、桃粉甜美妆、新中式玉兰妆、Y2K 桃粉玻璃唇妆。
- 服饰道具成立：服饰颜色、材质、饰品和主道具都从妆容气质往外长，而不是抢走妆容主体。
- 构图成立：半脸裁切、玻璃反射、手或道具前景、门框 / 电梯框中框、近距离大胆裁切。
- 镜头成立：低机位、俯拍、门框窥视、枝叶缝隙、近距离广角、长焦浅景深。
- 动作表情成立：低头触花、手扶桌面、整理头发、抬手挡光、拿道具靠近脸、冷淡直视、眯眼大笑。
- 光线成立：高调奶油柔雾、直闪 CCD、树荫斑驳光、侧逆光、午后窗光、强夏日自然光、局部过曝。
- 关系成立：妆容、服装、道具、光线、构图和场景都属于同一个世界。

妆容必须先定。先从已有参考、妆容方法卡和已跑通样张里选一个妆容母体，再做同系发散；不要凭空发明怪妆、猎奇妆、病态灰妆、脏灰烟熏、怪异撞色或压眼脏眼妆。服饰搭配和道具元素必须根据这个妆容设计，回答“它们是不是让这个妆容更成立”。

当前写真探索的人物状态基线是成年年轻女性，视觉年龄感偏 18-22 岁，整体要活泼、灵动、轻盈、有生命力。这里的年轻只指成年后的青春气质，不写未成年、儿童化或幼态；默认避免成熟姐姐感、贵妇感、商务端庄、疲惫冷淡和过度稳重。

场景最后才定。场景只问三件事：能不能服务妆容，能不能提供构图和前景，能不能产生想要的光线质感。如果不能，场景再新也不要用。

如果用户明确“棚拍 / 不搞场景 / 纯棚拍 / studio”，场景不再作为探索变量，只写低变量棚拍容器：灰白无缝背景、黑灰棚布、白色桌面区、反光板、亚克力反射面或简单地台。不要自动扩展成办公室、街区、海边、花园、咖啡馆等地点；道具只服务构图、妆面和光线落点。

成立点只用于内部组织，不在最终提示词中单独输出。

### 2. 场景和道具必须拆开写

场景只负责宏大描写：空间类型、时代气质、季节、天气、城市 / 自然 / 室内关系、整体氛围。场景里不要重复具体道具，也不要替代人物妆造、构图、镜头和光线成为主变量。

道具元素负责罗列整个系列能使用的具体物件，包括饰品、手持物、前景遮挡、桌面物、环境小物。每个道具之间用 `/` 划分。

道具元素模块结尾必须写这句：

```text
（道具根据实际构图需求选取，不要将所有的道具全都塞进一个画面中）
```

这样既能保留系列图的道具池，又不会把所有物品塞进同一张图。

### 3. 风格要写成成像方式

不要只靠“高级、电影感、氛围感”这类虚词，要把风格翻译成拍摄逻辑：

- `35mm film photography`：自然颗粒、轻微色偏、夏日户外、真实抓拍。
- `direct flash` / `CCD`：机顶闪光、硬阴影、皮肤轻微反光、现场感。
- `Pro-Mist` / 柔雾棚拍：低对比、亮部化开、奶油高光、柔光包裹。
- 压暗环境 + 柔闪 bloom：环境亮度压低一到两档，人物承接柔化闪光，脸颊、发丝、肩颈和金属饰品出现高光弥散、柔焦 bloom、银色边缘光和局部光斑。
- 中长焦人像：85mm / 105mm / 135mm，浅景深，焦点落在人眼，背景压缩。
- 手机抓拍：轻微运动模糊、近距离、偶然遮挡、现场瞬间。

当英文摄影词更有利于模型理解画面时，可以保留英文。

成像机制只负责“照片如何被记录和呈现”，不是把同一盏灯复制到整组图。系列可以固定 `CCD / direct flash` 的快照响应、反差和颜色，但每张现场闪光的方向、强度、落点、高光宽度和皮肤反射必须随景别与动作重新设计。全身环境照可以保留较强主体分离；面部近景要降低闪光强度或缩小高光区域，不能继续使用覆盖额头、鼻梁和双颊的同一套强反光。

### 4. 妆容写最小可识别锚点

不要把妆容写成完整化妆教程。只抓几个可见锚点：

```text
【妆容名】，【底妆质感】，【眼妆锚点】，【腮红 / 面中颜色】，【唇妆锚点】，【与道具或场景的色彩关系】。
```

好用例子：

- 桃粉甜美妆、奶油肌、眼下桃粉腮红、水润桃粉唇、果实发串。
- 清透奶油裸妆、自然卧蚕、浅粉唇、轻微真实皮肤纹理。
- 冷白皮直闪职感妆、半哑光底妆、黑框眼镜、低饱和唇色。

#### 皮肤纹理与皮肤反射分开写

`真实皮肤微纹理`只控制毛孔、绒毛、细小纹理和肤色变化，不控制皮肤表面怎样反光。每条涉及人脸的 prompt 还要根据当前景别选择皮肤反射：

- 没有明确水光肌、汗湿事件或参考证据时，默认自然半哑光或克制缎光；T 区高光受控，脸颊以柔和漫反射为主。
- `水润唇、玻璃唇、湿润眼妆`只作用在对应五官区域，不能自动扩散成额头、鼻翼和双颊的连续湿亮。
- 近景 / 美妆特写要写区域：额头大面保持半哑光，鼻梁只留窄高光，鼻尖与眼下不形成大片白亮，脸颊保留柔和肤色层次。
- 半身 / 全身只保留一条高信号约束，例如“自然缎光皮肤，T 区高光克制，双颊不湿亮”，不要堆完整皮肤教程。
- 只有炎热运动、刚跑完、雨水、泳池或用户明确水光肌时才增加汗光 / 湿亮；仍要写发生区域与场景因果，例如发际线和鼻尖少量汗光，而不是全脸均匀油膜。

高风险组合是：`直闪 + 正午硬光 + 轻微过曝 + 清透妆 / 水润唇 + 面部近景`。这类组合必须同时给出正向反射控制，不能只在末尾补“不要油腻”：

```text
自然半哑光底妆，额头与双颊保持柔和漫反射，T 区只有克制的窄高光，水润质感只保留在唇部；直闪提亮眼神和服装边缘，不在脸上形成连续油膜。
```

如果成片已经出现油腻感，下一轮先减少覆盖脸部的闪光强度和过曝范围，再补区域反射；不要只增加“真实毛孔、真实纹理”，否则可能得到“有毛孔的油亮皮肤”。

妆容要服务场景：桃子和腮红要像同一个世界；兰花和柔雾光要服务柔软棚拍。

自动化写真探索时，妆容必须来自已有基础再发散，不要怪和猎奇。允许从白开水妆、青苹果氧气妆、玫瑰水光妆、红茶千金妆、冷欲猫系妆、桃粉甜美妆、新中式玉兰妆、Y2K 桃粉玻璃唇妆等方向里取母体；新妆容必须说明继承哪个母体，只变化底妆质感、眼妆锚点、腮红位置、唇色质地或搭配锚点中的 1-2 项。

为了保持年轻灵动的总方向，默认优先选择青苹果氧气妆、桃粉甜美妆、玫瑰水光妆、Y2K 桃粉玻璃唇妆、白开水妆这类清透轻盈的妆容母体。红茶千金妆、新中式玉兰妆、冷欲猫系妆也可以用，但要降低成熟感，改成更清透、更活泼的同系变体。

#### 人物参考先分配职责：身份参考与风格参考不能混写

人物出现在参考图里，不代表这张图自动承担人物身份参考。先判断用户要带走的是“这个人”还是“这张照片如何被拍出来”，再写 Prompt。

**人物身份参考**用于继续生成同一个人：

- 只保留脸型轮廓、眼型 / 眼神、鼻唇关系、发际线和肤色气质等少量身份锚点。
- 目标系列接管妆容、发型、服装、饰品、场景、道具、光线和情绪。
- 不保留参考图原妆容、原发型、原服装、原场景，除非用户明确要求。
- 可写：`参考图用于保持同一位成年人物的五官辨识度；角色已经完成目标系列妆造后再进入新的拍摄现场。`

**风格参考**用于迁移摄影质感而不是复制参考人物：

- 只提取有可见证据的媒介、白平衡与色偏、反差曲线、黑位、高光响应、锐度、噪点或颗粒、压缩痕迹、景深、构图习惯和情绪逻辑。
- 不继承参考图中人物的脸，不要求逐项复刻脸型、眼型、痣、鼻唇关系或其它身份特征，也不增加人物身份相似度验收。
- 用一个可替换的人物类型变量正向重新造人。固定句式是：`本张重新生成一位「【原创女性类型】」类型的成年原创女性，不要继承参考图中人物的脸。`
- 实际 Prompt 必须把 `【原创女性类型】` 替换成当前主题需要的内容，例如 `韩系混血甜酷辣妹`、`清冷东方文艺女性` 或 `明艳复古港风美人`；不要把占位符原样提交给模型。

风格参考的最小职责合同：

```text
图 1–图 N 只负责整体摄影风格与成像质感，不承担人物身份参考。
只提取并保持【媒介、色彩、反差、高光、锐度、噪点 / 颗粒、压缩、景深、构图习惯与情绪逻辑】。
本张重新生成一位「【原创女性类型】」类型的成年原创女性，不要继承参考图中人物的脸。
```

#### 完整写真企划复拍另走独立模式

普通风格参考仍按上面的最小职责合同写 Prompt。用户真正要的是“换一位人物，像去同一家摄影店按同一企划重新拍一组新照片”时，不把它压缩成普通同系列变体；改读 [摄影方案复拍工作流](production-reshoot.md)，从整组参考提取共同写真套餐、布光子方案、色彩曝光与成像系统，再重新设计分镜。

摄影方案复拍直接使用原始参考图并在 Prompt 中逐图分配职责，不制作抽象控制卡，不汇总多种布光的综合色彩统计，也不设置校准样张。每张正式生成只选择同一布光子方案中的主参考和少量辅助参考。

参考图同时承担身份和风格，只有用户明确要求“同一个人保持原脸并迁移这组摄影质感”时才成立；不得因参考图里有人脸就自行扩大为身份参考。

### 5. 穿搭只写服装

穿搭模块只写服装本身：上衣、下装、外套、裙装、鞋靴、袜子、面料、颜色、版型、层次和穿着方式。

不要在穿搭里写耳环、项链、发饰、眼镜、手链、戒指、腰链、帽饰、手持物、包、伞、花、饮料等饰品或道具。它们统一放进道具元素。

### 6. 动作写骨架，不写人体难题

动作与表情模块必须用自然语言描述角色正在做什么、脸上是什么情绪，不要只堆动作词。动作要有清楚的身体逻辑：

- 低头垂眼，手指轻触桌面花瓣。
- 坐在草地晒太阳，不强求看向镜头。
- 从果树枝叶之间跑过，笑着侧身但头肩方向一致。
- 手拿桃子靠近脸部，近景抓拍。
- 站在白板旁，手扶桌面，直闪看镜头。
- 抬手挡光、低头整理发丝、拎篮经过、拨开枝叶。

不要要求人物同时完成太多复杂动作。好的动作骨架能给画面动势，但不会让人体结构变成解题考试。

### 7. 镜头角度和构图分开写

镜头角度只写拍摄视角和机位：低机位、俯拍、平视、侧前方、门框窥视、枝叶缝隙、近距离、远景、半身、全身、长焦压缩、广角贴近等。

构图只写画面组织方式：人物位置、主体比例、前景遮挡、背景层次、留白、框中框、对角线、中心构图、三分法、大胆裁切、浅景深等。

### 8. 光线写成“来源、落点、结果”

光线按这个链条写：

```text
【光源】从【方向】进入，落在【皮肤 / 发丝 / 服装 / 道具 / 前景】上，形成【高光 / 阴影 / 眩光 / 颗粒 / 柔雾 / 亮部轻微溢出】。
```

例子：

- 大面积柔光从正前方和侧前方包裹人物，落在脸颊、手指、白色桌面和兰花花瓣上，形成低对比奶油高光，亮部轻微溢出但不要死白。
- 机顶直闪直接打在人物脸部、黑框眼镜和白板边缘，形成硬阴影、皮肤轻微反光和夜间办公室现场感。
- 环境亮度压低一到两档，柔化闪光从镜头方向和侧前方照向人物，落在脸颊、鼻梁、发丝、肩颈和金属饰品上，形成强主体突出、高光弥散、柔焦 bloom、银色边缘亮和零散局部光斑。
- 夏日自然光穿过树叶，落在草帽、发丝、脸颊和前景花朵上，形成斑驳光、轻微眩光和浅景深柔焦。

使用直闪时继续检查景别：近景把闪光主要落在眼神、鼻梁窄线、发丝和服装边缘，脸颊保持柔和漫反射；半身和全身可以提高主体分离，但仍不能让额头、鼻梁与双颊连成同一片白亮油膜。`轻微过曝`必须指明落点，不能作为覆盖整张脸的统一结果。

### 9. 随机与变体要分开

锁住骨架，让画面呼吸：

- 固定：人物妆造、构图核心、主镜头关系、光线质感和审美骨架；场景只在能服务这些变量时固定。
- 可变：动作、表情、镜头距离、前景遮挡、视线方向、选用道具。

系列提示词可以写：

```text
保持【场景 / 光线 / 妆造 / 风格骨架】不变，只让【动作 / 表情 / 镜头距离 / 前景遮挡 / 是否看镜头】自然变化。
```

“随机”用于一条母版内的小范围抽取，可以锁住妆造、场景和光线骨架；“同系列变体”是另一种任务。变体只锁定整体风格和成像机制，人物外貌、妆容、发型、服装、场景、道具、镜头角度、构图、身体动作、手部关系、表情、视线和现场光线默认都可以重新设计。参考图提供的是系列审美与成像证据，不是逐项照抄清单。

### 10. 元素之间要互相认识

最终输出前，检查画面元素是否属于同一个世界：

- 桃子、腮红、唇色、发饰、夏日逆光应该互相服务。
- 草帽、树荫、花田、蓝天、低机位应该互相服务。
- 白板、公式、证件挂绳、黑框眼镜、直闪应该互相服务。
- 兰花、白桌面、奶油裸妆、柔雾光应该互相服务。

如果提示词读起来像购物清单，就删掉冲突项，或者补一句说明它们之间的关系。

### 11. 主题色和核心造型要跨模块锁定

主题色不是在风格词里写一次颜色就结束，而是要贯穿服装、发饰、道具、场景辅助色、前景遮挡和光线落点。尤其是用户要求“主题色替换成某个颜色系”时，要把正确颜色写成正向系统，同时把上一轮容易跑偏的颜色写进负面约束。

好用写法：

- 正向系统：整张图的主题色必须是绿色系，薄荷绿、鼠尾草绿、嫩叶绿、奶油绿为主；发饰、服装、主花材、画材和前景虚化都服务绿色主视觉。
- 穿搭锁定：浅绿色蕾丝无袖上装 + 浅绿色蓬蓬半裙 / 同色薄纱层次；不要只写“绿色系服装”，要写清上装、下装、材质和轮廓。
- 发饰锁定：发饰更换为绿色丝带、绿色蝴蝶结、绿色叶片发夹；如果参考图有强记忆发饰，同时写“不要白色钩花头巾 / 不要原发饰”。
- 光线锁定：窗光落在绿色发饰、绿色上装、绿色裙摆、绿色主道具和前景叶片上，让颜色成为被照亮的主体。
- 跑偏项反制：如果上一轮出现牛仔裤、红裙、白上衣、白色主视觉，就在下一轮负面约束里明确写“不要牛仔裤、不要蓝色裤子、不要红色裙子、不要白色上衣、不要白色主视觉”。

颜色替换时，不要只换服装颜色。正确做法是替换整组画面的色彩系统；保留成像方式、场景和光线骨架，让颜色成为新的系列识别点。

### 12. 多张变体先做差异矩阵

用户要 3 张、5 张或一组变体时，先在内部给每张图设计完整的观看关系和人物事件，再写具体 prompt。差异矩阵用于防重复，不等于每张只准变化 1-2 项。变体可以同时重写人物、妆发、服装、场景、道具、镜头、构图、动作、手部、表情、视线和现场光线；只要整体风格词链与成像机制词链保持逐字一致即可。

下面只是当前主题成立时可用的差异示例，不是跨系列复用的固定模板：

- P01：主道具或妆容特写变化，例如调色盘靠近镜头。
- P02：镜头关系变化，例如复古 DV 反拍摄影师或平视半身。
- P03：机位变化，例如地板低机位坐姿、靴子和腰线入镜。
- P04：动作变化，例如抬手挡光，让光线打在手臂和脸上。
- P05：横向构图或侧前方动态变化，例如人物从画面边缘走入硬光里。

保持不变的层：整体风格词链、成像机制词链。

允许变化的层：人物外貌、妆容、发型、服装、场景、道具、镜头角度、景别、构图、身体朝向、动作、手部关系、表情、视线、情绪和现场光线。只有用户明确点名的内容才额外固定。

同一组里“递道具靠近镜头”最多出现 1 张；如果已经用过耳机、相机、饮料或画具递向镜头，后续必须改成低机位坐姿、平视半身、侧前方动态、横向裁切、局部手臂 / 腰线 / 靴子入镜、背光边缘光等不同观看关系。

如果某张生成后明显跑偏，不要简单“再来一张”。先识别跑偏层，再在下一条 prompt 里同时做两件事：正向重申正确层，负面排除跑偏层。

### 13. 系列母版必须固定输出格式

用户明确说“系列母版、一整套系列规划、扩展系列骨架、按前面那种格式、总合成前面那种系列母版、固定格式输出”时，默认输出系列母版，不要归入普通详细提示词。只要触发词里明确出现“变体”，优先进入下一节的同系列变体关键词链，不再自动归入系列母版。

系列母版的固定结构：

```text
【系列母版：主题名】

【比例】比例 + 摄影器材 + 风格词，写清主成像方式、场景气质和系列情绪。

【五官/脸型】+【妆容】+【发型】

【穿搭】：服装池，不能写饰品；大胆服装必须保持成年时装 editorial 质感和真实可穿逻辑。

【场景】：宏大环境和空间气质，不重复道具。

【道具元素】：道具池 / 饰品池 / 手持物 / 前景遮挡 / 环境小物（道具根据实际构图需求选取，不要将所有的道具全都塞进一个画面中）

【镜头角度】：系列可变化的机位关系。

【构图】：人物占比、框中框、裁切、背景层次和签名位置。

【动作与表情】：
P01：具体画面任务。
P02：具体画面任务。
P03：具体画面任务。
P04：具体画面任务。
P05：具体画面任务。
P06：具体画面任务。
P07：具体画面任务。
P08：具体画面任务。

【光线与质感】

【可以随机的变量】

【负面约束词】
```

P01-P08 默认 8 张；用户指定张数时按用户数量。每个 P 编号必须是一个可直接拍摄的画面任务。这里是规划母版，所以 `【可以随机的变量】` 仍按该母版自己的约束填写；不要把母版的小范围随机规则冒充为同系列变体规则。

### 14. 同系列变体必须编译为关键词链

用户说“变体、同系列变体、系列变体、创作变体、扩展变体、仿拍扩展、同主题不同成片”时，直接进入本模式。它不是系列母版的小修，也不是把详细提示词的模块标题重复十遍。

先在内部拆成两类：

- 固定层：只保留 `整体风格词链` 与 `成像机制词链`。前者回答这组图属于什么审美世界，后者回答照片如何被拍出来、如何显影和呈现质感。
- 变量层：人物外貌、妆容、发型、服装、场景、道具、镜头角度、构图、身体朝向、动作、手部关系、表情、视线、情绪和现场光线。用户明确要求保留的内容可以额外固定，但不能擅自扩大固定范围。

两个固定层的边界必须窄而清楚：

- `整体风格词链`：审美语法、时代 / 编辑气质、色彩组织、叙事距离。不要塞入具体人物、妆发、服装、场景、道具、姿势或表情。
- `成像机制词链`：拍摄媒介、镜头响应、曝光 / 对比曲线、颗粒、锐度、压缩和皮肤呈现。现场光源、方向、光色和落点属于本张变量，不要因为写了“光线质感”就把十张都锁成同一盏光。
- 成像机制可以固定“自然皮肤、低磨皮、克制高光”的总体呈现，但具体额头、鼻梁、双颊怎样反光属于本张现场光线，不能逐字复制成相同高光面积。变体包含近景时必须重新评估闪光强度和皮肤反射。

固定词链必须来自当前参考图或当前提示词的共同证据。同组每条最终 prompt 中，两段固定词链都要逐字复用；不要用同义词改写，不要在变量层加入新的摄影流派、媒介、滤镜或风格形容词覆盖它们。

参考组图用于编写普通变体 Prompt 时，不能只翻译成宽泛的“复古、电影感、旧数码”后丢掉视觉控制；仍要写清成像机制。用户同时要求换人物、还原整套摄影企划并直接生图时，转入 [摄影方案复拍工作流](production-reshoot.md)，不要把两种模式混写。

成像机制词链至少回答：白平衡偏冷还是偏暖、主色与肤色怎样相互影响、黑位抬高还是压低、高光柔和溢出还是硬裁切、边缘锐度和微反差、噪点 / 颗粒 / 压缩、景深与焦点衰减、是否存在现代商业调色。参考图没有证据的质感不能凭空补入。

每张先在内部设计不同的观看关系和人物事件，再按以下顺序编译：

```text
整体风格词链 -> 构图与机位 -> 人物与脸部可见区 -> 眼神与微表情 -> 身体动作、手部与道具关系 -> 妆造、服装与材质 -> 场景 -> 现场光线与色彩 -> 成像机制词链 -> 紧凑失败防线 -> 用户明确要求的可选署名
```

最终 prompt 是一个连续中文段落，用逗号、顿号和分号叠加高信号关键词与短语义片段，不显示 `【构图】`、`【穿搭】`、`【光线与质感】` 等分析标题。详细拆解只用于内部推理或按用户要求展示，不能原样提交给生图模型。

差异设计必须服从当前系列自身的审美逻辑，不套用固定的“低机位、递道具、抬手挡光、回头看”变化模板。任意两张如果在镜头角度、构图重心、身体动作、手部关系、表情、视线和情绪上大部分相同，就自动重构其中一张。变量层优先写可观察事实；没有参考证据或用户要求时，不自动加入“撩人、妩媚、欲感、慵懒勾人、性感氛围、精致高级、完美无瑕”等风格修饰词，禁止靠夸张媚态、表演性挑逗、过度妆发、湿亮塑料皮肤或浓重商业精修来伪造差异。

## 四种提示词输出模式

### 1. 系列母版

系列母版用于先规划一整套系列、扩展系列骨架和固定格式输出，适合这些场景：

- 用户明确要“系列母版 / 一整套系列规划 / 扩展系列骨架 / 按前面那种格式 / 总合成前面那种系列母版”。
- 用户希望一次得到 5-8 张甚至更多图的共同骨架和每张差异任务。
- 用户需要后续把每个 P 编号拆成单张完整 prompt 或批量生成。

系列母版的写法是“妆容母体 + 共同视觉 DNA + 分张变量矩阵”：先锁定妆容母体和同系变体边界，再让穿搭方向、道具池、镜头池、构图规则、光线质感和场景承托服务妆容；P01-P08 只负责分张动作、表情、镜头关系、主道具和光线落点变化。

### 2. 同系列变体关键词链

同系列变体关键词链用于把参考组图或已有系列真正扩展成不同成片，适合这些场景：

- 用户说“变体 / 同系列变体 / 系列变体 / 创作变体 / 扩展变体 / 仿拍扩展 / 同主题不同成片”。
- 用户要求保留系列感，但不要复刻原图角度、构图、姿势、表情和视线。
- 用户准备直接生图，需要每张都是紧凑关键词链，而不是分析卡或母版模块。

这类输出只固定整体风格词链和成像机制词链，其他内容根据当前系列重新设计。输出多张时使用 `P01 / P02 / ...` 区分，但每个 P 下只有一段完整、可直接提交生图的关键词链。

### 3. 详细提示词

详细提示词用于精准控制画面，适合这些场景：

- 用户要完整 prompt、复刻某张图、稳定生成、直接复制进模型。
- 用户已经确定主题，希望控制比例、成像方式、人物妆造、服装、场景、道具、镜头、构图、动作、光线和负面约束。
- 用户要同步 Eagle 或做案例沉淀，需要完整 prompt 可追溯。

详细提示词的写法是“拍摄小抄”：每个模块都写成自然语言，让模型知道画面怎么拍、人物怎么站、光怎么落、道具怎么用。

### 4. 抽卡关键词

抽卡关键词用于网页端大量生成和探索方向，适合这些场景：

- 用户说“抽卡、网页端、大量生成、短关键词、少量关键词、开盲盒、探索方向”。
- 用户想用同一个审美骨架跑很多图，不想每张都被完整分镜锁死。
- 用户还在找方向，需要让模型自己组合场景、动作、镜头和道具。

抽卡关键词的写法是“风格 DNA + 变量池”：

- 保留：比例、主成像方式、写真主题、人物妆造锚点、服装方向、场景 / 道具池、镜头光线、动作表情池、轻量负面。
- 放开：具体动作、具体表情、具体场景子空间、具体服装组合、前景遮挡、镜头距离、是否看镜头。
- 不写完整自然语言分镜，不把每个模块都填满，不要把所有变量锁死。
- 控制在 6-8 行，方便复制到网页端；每行用逗号、顿号或 `/` 组织。

抽卡关键词不是弱化版提示词，而是为了扩大生成分布。它必须保留画面成立点，比如“CCD 直闪 + Y2K 街头 + 真实皮肤 + 近距离广角 + 俏皮动作池”，不能只写“美女、氛围感、电影感”。

### 5. 模式选择

- 默认：如果用户只说“给我 prompt / 生图提示词”，输出详细提示词。
- 明确变体：只要用户说“变体 / 同系列变体 / 系列变体 / 创作变体 / 扩展变体 / 仿拍扩展”，输出同系列变体关键词链。
- 明确系列母版：如果用户提到系列母版、一整套系列规划、扩展系列骨架、按前面那种格式或固定格式输出，输出系列母版。
- 明确抽卡：如果用户提到网页端、大量生成、抽卡、短关键词，输出抽卡关键词。
- 详细 + 抽卡都要：先输出详细提示词，再输出抽卡关键词。
- 系列母版 + 抽卡都要：先输出系列母版，再输出抽卡关键词。
- 图片拆解后继续生成：根据用户目标选择详细版或抽卡版；没有说明时，先给拆解结果，不默认继续扩写。

## 用户样本偏好层

用户提供的离线生图样本，作用是沉淀写法机制和审美偏好，不是建立固定内容模板。每次生成 prompt 时，只选取与当前主题匹配的少量偏好；不要把猫系、豹纹、海边、古风、果园、欧式室内和暗调辣妹等样本元素混在同一张图里。

写真自动化探索要先吸收已有参考里的妆容经验：先选妆容母体，再根据妆容选择服饰、发型、饰品、主道具和棚拍容器；不要把“新奇妆容”当创新点。

当前用户追求的整体状态是活泼灵动的年轻写真。默认人物写成年年轻女性，不写成熟姐姐、贵妇、商务端庄或疲惫冷淡；动作表情要更像被摄影师抓拍到的轻快瞬间，而不是安静坐姿、端庄半身或过度轻熟的棚拍。

当前年轻甜酷棚拍方向里，不再默认使用亚克力板、透明板、玻璃板或玻璃苹果；这些会把画面带回清透道具棚拍。需要前景和反光时，优先用有线耳机、复古数码相机、贴纸、金属腰带、银色反光板、白色平台和服装金属细节。服装优先成年 Y2K 甜酷辣妹时装，例如修身运动上衣、短外套、工装裤、金属腰带、厚底靴；不要退回端庄针织、温柔开衫、生活感桌面或成熟贵气穿搭。

如果上一轮被反馈 AI 感重，下一轮提示词要主动减少“完美、干净、对称、统一精修感”，增加真实拍摄里的皮肤细小纹理、局部高光不均、碎发、服装褶皱、轻微运动虚焦、抓拍感和不完全标准的表情；重点是像一次真实棚拍试片，不像统一美颜模板。

### 1. 高频风格入口

这些可以作为“比例 + 摄影器材 + 风格词”的候选入口，按主题选择一个主入口即可：

- Y2K 猫系街头：CCD 摄影、元气甜酷街拍、近距离广角、硬光、轻微过曝、紧凑构图。
- 豹纹复古直闪：夜室内、低照度奢华暗调、direct flash、背景压黑、豹纹与金属反光。
- 橘子汽水海边：夏日海边、Y2K 度假、CCD / 数码卡片机、蓝天高饱和、柔焦泛白。
- `overexposed tropical VHS travelogue`：热带旅行感、blown highlights、泛朦柔光、明亮低对比。
- 古风旧室鸟笼：尼康相机摄影、旧木案、窗外白雾逆光、film halation、旧镜头低对比。
- 雏菊花丛富士：户外富士相机摄影、昆虫视角、花丛缝隙、夏日高光和前景柔焦。
- 夏日果园 35mm：真实胶片摄影、绿色反射光、树荫斑驳、果实前景、皮肤细碎光影。
- 复古欧式柔雾室内：午后窗边自然光、Pro-Mist 柔雾、bloom、局部高光 clipping、浪漫私密。
- 暗调强身份道具写真：低饱和暗调、强身份道具、局部高光、压迫感和自由感并存。

### 2. 高频成像词

一张图优先只选一个主成像系统，再配一两个辅助质感词：

- CCD / 数码卡片机：近距离、硬闪、轻微过曝、真实随拍、现场感。
- `direct flash`：机顶闪光、皮肤局部过曝、背景快速衰减变暗、眼部高光明显。
- `35mm film photography`：自然颗粒、轻微色偏、户外抓拍、真实皮肤质感。
- 富士 / 尼康相机摄影：可作为风格记忆词，但要落到色彩、光线和镜头关系上。
- VHS / travelogue：泛白高光、轻微朦胧、旅行记录感、不过分锐化。
- `Pro-Mist` / `bloom` / `film halation`：柔雾、高光化开、边缘泛光、旧镜头低对比。

不要把 CCD、VHS、35mm film、商业棚拍、手机自拍和超清质感同时塞进同一条 prompt。混用会让模型不知道该模拟哪种照片。

### 3. 真实皮肤写法

用户样本里的皮肤偏好是“真实、可见、有光感”，不是零毛孔磨皮，也不是全脸湿亮。默认可以写：

- 保留真实皮肤纹理、自然毛孔、细小瑕疵、唇纹、皮肤绒毛、轻微肤色不均。
- 没有明确水光肌或出汗事件时，使用自然半哑光 / 克制缎光底妆，T 区只有窄而克制的高光，双颊保持柔和漫反射。
- 夏日户外只有在炎热、运动或刚跑完等事件成立时才增加轻微汗光，并限定在发际线、鼻尖等局部；不要默认增加全脸皮脂光泽。
- 直闪或强日光可以写皮肤局部轻微过曝，但要写明落点；近景不让额头、鼻梁和双颊同时出现大片高光。
- `水润唇、玻璃唇、湿润眼妆`只约束对应五官，不代表水光底妆。
- 负面约束里默认排除塑料皮肤、全脸连续油膜、湿亮蜡感、过度磨皮、过度锐化和廉价美颜滤镜。

### 4. 场景元素池

用户样本常用“场景池 + 道具池”而不是单张道具清单。写法规则：

- 场景模块只写一个宏大子场景，例如便利店门口、夜室内复古书房、夏日沙滩、旧木室内、花田、果园、欧式卧室。
- 棚拍不是“无场景”，而是低变量拍摄容器；用户明确要棚拍时，只写背景纸、棚布、白色桌面区、反光板、亚克力板、简单地台等拍摄条件，不另行发散具体生活地点。
- 道具元素模块列整个系列能用的道具池，用 `/` 分隔。
- 单张图只突出一个主道具，再配两三个辅助元素；不要把道具池全部塞入同一画面。
- 前景遮挡可以来自叶片、花、鸟笼栏杆、电话听筒、玻璃瓶、窗帘、书页、扶手、栏杆等，但要服务机位和构图。

### 5. 动作表情随机

用户写“xxx 随机”“由摄影师指导”“动态”时，最终提示词不能保留占位词，要替换为具体动作和表情：

- 动作要有身体支撑点、手部任务和镜头关系，例如身体前倾、抬手挡光、拨开枝叶、靠近电话听筒、坐在扶手椅上交叠双腿、手持雏菊递向镜头。
- 表情可以更怪、更灵动：挑眉、wink、鼓脸、吐舌尖、嘟嘴、张嘴笑、低头抬眼、看向画外偷笑。
- 系列图里每张动作、姿势、表情都要不同；同一风格下仿拍的是成像逻辑和气质，不是照抄上一张的姿势。
- 保持头肩方向自然一致，优先用正面迎镜头、侧身但头肩同向、低头整理、抬手挡光和环境互动。
- 年轻灵动是默认优先级：浅笑、眯眼笑、张嘴笑、wink、鼓脸、挑眉、低头偷笑、看向画外偷笑、身体前倾靠近镜头、递出道具和拨开前景优先；冷淡直视、疲惫松弛、贵气端坐和安静疏离只能作为少量对照。

### 6. 特殊机位和大胆裁切

用户样本偏好有“镜头像藏在现场里”的感觉，可以使用：

- 昆虫视角、花丛缝隙视角、物品视角、桌面低机位、房间内物品角度、低机位广角、轻俯拍、高俯拍、近距离自拍感。
- 前景虚化、大花遮挡、叶片遮挡、鸟笼栏杆遮挡、栏杆切割、局部裁切手臂 / 头发 / 腿部边缘。
- 当用户要求同系列变体“构图意想不到一些”时，先设计观看关系，再设计人物动作：相机可以藏在门后、窗格后、水面旁、二楼屋檐、花枝缝隙、桌面低处或暗部边缘；人物动作必须属于那个空间。最小判断规则是：先确定相机实际藏在哪里、哪些真实前景会遮挡镜头、人物为何会进入这条视线，再让动作响应空间；不要先写猎奇机位，再把一个与现场无关的姿势塞进去。
- 人物靠近镜头时要写脸部清晰、身体向后延展、广角轻微畸变；不要让特殊机位牺牲五官和身体连接。

### 7. 光线必须落在人身上

如果用户强调“光线打在人身上”，光线模块要写得更具体：

- 写清光源：正午硬阳光、CCD 直闪、机顶闪光、柔化闪光、午后窗光、窗外白雾逆光、树荫斑驳光、海边反射补光、植物漏光。
- 写清落点：脸颊、鼻梁、锁骨、肩颈、发丝、手臂、胸口衣料、薄纱边缘、金属饰品、前景花瓣。
- 写清结果：局部高光 clipping、轻微过曝、硬阴影切割、高光弥散、银色 bloom、边缘泛光、柔焦高光、草帽筛孔光斑、局部光斑、背景压暗、浅景深高亮虚化。
- 年轻甜酷棚拍里，光必须明确打在人身上，优先写脸颊、鼻梁、眼下腮红、玻璃唇、发丝、外套肩线、手臂、上衣纹理、裤装缝线和金属细节；不要只把光写在亚克力、玻璃、桌面或背景上。
- “打在人身上”不等于“整张脸都反光”。近景优先把高光落在眼神、鼻梁窄线、唇部、发丝和服装材质上，额头大面与双颊保持半哑光或柔和漫反射；半身和全身再根据人物占比增加闪光强度。

### 8. 签名文字

默认不添加任何署名或水印。只有用户明确要求署名并提供文字时，构图模块才可以加入：

```text
右下角加入不起眼的小字艺术签名“【用户指定文字】”，不要变成明显水印。
```

不得自行填写作者名、账号名或 `nuyoah`。负面约束里可以写“不要额外文字水印”，但不要让它与用户明确要求的签名互相冲突。

### 9. 身体与服装视觉重点

“清凉”“少量”“强调上围”只在用户明确提出时作为视觉重点进入 prompt，不要变成所有写真默认项。写法要落在摄影和服装结构上：

- 用“上半身视觉重心、肩颈线条、吊带版型、胸口衣料高光、腰线比例、服装面积少、真实可穿的成年时装写真”来组织画面。
- 避免把服装写成复杂怪异的镂空、机能堆叠或不现实结构，除非用户明确要求这种造型。
- 当使用“少女感、娃娃感、cosplay、猫系撒娇感”等词时，同时写清成年女性气质和避免幼态化，让画面保持时装写真感。

## 每个模块的书写规则

最终提示词虽然是模块化输出，但每个模块都要像摄影现场小抄，不要像表格填空。默认遵循 `image-2` 人像方法：高信号、少冲突、可观察、可拍摄；第一版不要同时堆满质量词、相机参数、胶片词和修图词。

### 【比例】+【摄影器材】+【风格词】

- 比例放最前面，例如 `9:16`、`4:5`、`3:4`、`1:1`。
- 摄影器材写成成像方式和观看关系，不迷信复杂参数。优先写一个主设备感：`35mm film photography`、`CCD direct flash`、手机近距离抓拍、85mm 中长焦人像、柔雾棚拍、全画幅自然光人像。
- 风格词必须落到画面里：真实胶片、直闪生活快照、柔雾商业棚拍、雨夜霓虹街拍、低饱和 editorial portrait、夏日户外抓拍。
- 不要一口气同时写 CCD、电影胶片、Vogue 棚拍、手机自拍、8K 超清和强颗粒；一张图只保留一个主成像逻辑。
- 如果用户给了多个样本风格，只选与当前主题最匹配的一个成像入口，再把其他样本里的可通用机制转成变量，不要跨风格硬拼。

### 【五官/脸型】+【妆容】+【发型】

- 五官和脸型写可见锚点：脸型轮廓、眼睛气质、鼻梁、唇部状态、整体气质；不要写成泛泛的“绝美、精致、高级”。
- 默认人物气质写成年年轻女性，视觉年龄感偏 18-22 岁，活泼灵动、轻盈有生命力；不要默认轻熟成熟、贵妇端庄、商务证件照感、疲惫冷脸，也不要写未成年、儿童化或幼态化。
- 当使用人物参考图套目标系列时，本模块先写参考脸的少量身份锚点，再写目标系列妆容和发型；不要把参考图的原妆发混进来。
- 妆容用最小可识别锚点：妆容名 + 底妆质感 + 眼妆锚点 + 腮红 / 面中色彩 + 唇妆锚点 + 与场景或道具的色彩关系。
- 自动化探索里，先写妆容母体和同系变体边界，再写服饰和道具；不要先写服装或道具再给人物套一个临时妆容。
- 真实皮肤质感是默认正向锚点：自然毛孔、细小绒毛、自然肤色变化，以及与当前景别相符的区域反射。没有汗湿 / 水光肌证据时，不默认写轻微皮脂光泽；使用自然半哑光或克制缎光，避免零毛孔塑料感和全脸连续油膜。
- 如果使用“少女感、娃娃感、猫系、cosplay”这类词，必须同时写清成年女性气质、时装写真感和避免幼态化。
- 发型写发色、发型轮廓、刘海、碎发、蓬松度、湿润感或风吹感。
- 饰品不要放在这里。耳环、项链、眼镜、发饰、帽饰统一放进【道具元素】。

### 【穿搭】

- 只写服装本身：上衣、下装、外套、裙装、鞋靴、袜子、面料、颜色、版型、层次和穿着方式。
- 优先写服装怎样改变画面结构：肩线、腰线、裙摆、袖口、材质反应、上半身视觉重心、下半身节奏。
- 系列图可以写服装风格池，让同一审美下有自然变化；单张图可以写更明确的服装组合。
- 不写耳环、项链、发夹、眼镜、帽子、包、花、伞、饮料、手持物，这些放进【道具元素】。

### 【场景】

- 场景只写宏大环境、空间关系、季节、天气、时代气质和整体氛围，不重复具体道具。
- 可以写三层空间，但三层只写空间职责：前景有可遮挡空间、人物位于什么位置、背景是什么空间层次；具体叶片、花、电话、书、饮料等物件放进【道具元素】。
- 场景要让画面有拍摄现场感，例如夏日果园、夜间办公室、复古书房、便利店门口、棚拍白色桌面区、江南园林亭台、城市雨夜街口。
- 用户明确要棚拍或不搞场景时，场景模块只写棚拍背景的明度、反射面、地台 / 桌面和空间层次，不要凭空新增办公室、街区、海边、花园或咖啡馆等地点。
- 当用户给一串场景候选时，场景模块只选一个主子场景；其他候选可以进入【可以随机的变量】，不要在同一条 prompt 里平铺所有场景。
- 不要把场景写成道具清单，也不要只写“高级室内、梦幻户外、氛围感背景”。

### 【道具元素】

- 道具元素是整个系列可用的元素池，包括饰品、手持物、前景遮挡、桌面物、环境小物和能强化场景关系的小物件。
- 每个道具之间用 `/` 分隔。
- 道具必须服务照片成立点，不能为了丰富而堆砌。
- 如果道具池很多，单张构图默认只突出一个主道具和两三个辅助元素，其他道具留给系列变体。
- 模块结尾必须追加：`（道具根据实际构图需求选取，不要将所有的道具全都塞进一个画面中）`

### 【镜头角度】

- 只写拍摄视角和机位：平视、低机位、俯拍、侧前方、门框窥视、枝叶缝隙、近距离、远景、半身、全身、长焦压缩、广角贴近。
- 可以写观看关系：朋友突然按下快门、路人视角、被观察感、近距离私摄影、远距离抓拍。
- 可以使用用户样本里的特殊机位：昆虫视角、花丛缝隙、物品视角、桌面低机位、房间内物品角度、低机位广角、高俯拍、近距离自拍感。
- 不要把人物位置、留白、前景遮挡、框中框这些构图组织放在这里；它们属于【构图】。

### 【构图】

- 只写画面组织方式：主体位置、人物占比、前景遮挡、背景层次、留白、框中框、对角线、中心构图、三分法、大胆裁切、浅景深。
- 构图要服务系列变化：同一风格下可以变化景别、主体占比、前景遮挡和是否居中。
- 如果需要人物主导，就明确主体占画面的大致比例；如果需要意境，就明确人物更小、空间更大。
- 默认不写签名；只有用户明确要求并给出署名文字时，才在构图末尾写“右下角加入不起眼的小字艺术签名 `【用户指定文字】`，不要变成明显水印”。
- 不要把构图写成抽象气质词，要能让模型知道画面怎么摆。

### 【动作与表情】

- 必须用自然语言写角色正在做什么，以及脸上是什么情绪。
- 动作要有支撑点、方向和手部任务，例如手扶桌沿、低头整理发丝、抬手挡光、拎篮经过、拨开前景、靠墙抬眼。
- 表情要落在眼神、嘴角、眉头和头部角度上，例如直视但不讨好、嘴角放松、低头垂眼、像被闪光灯打断。
- 不要同时要求太多动作；一张图保留一个主要动作骨架即可。
- 用户写“xxx 随机”“动态”“由摄影师指导”时，最终提示词要替换成具体动作和具体表情，例如挑眉、wink、鼓脸、吐舌尖、抬手挡光、拨开枝叶、递花、咬吸管、托腮、低头抬眼。
- 默认避开回头看镜头、扭头回望、身体背向镜头但头转回镜头等容易造成头颈断裂的姿态。需要运动感时，改成头肩方向自然的侧身行走、向前奔跑、低头整理、抬手挡光或与环境互动。

### 【光线与质感】

- 光线按“来源 -> 落点 -> 结果”写：光从哪里来，落在脸、发丝、服装、道具或前景上，形成什么高光、阴影、眩光、柔雾、颗粒或硬闪效果。
- 一张图优先写一个主光逻辑：窗光、树荫漏光、机顶直闪、棚拍柔光、侧逆光、夜景霓虹反射。
- 当需要压低环境亮度凸显人物时，写“环境低曝光，人物承接柔化闪光”，再写高光弥散、柔焦 bloom、银色边缘光和局部光斑；不要把背景整体抬亮。
- 材质要写表面对光的反应：丝绸的高光、棉麻的哑光、皮革的反光、薄纱的透光边缘、金属的冷亮点。
- 如果用户想要“光线打在人身上”，必须写具体落点，例如脸颊、鼻梁、肩颈、锁骨、手臂、发丝、胸口衣料、薄纱边缘或金属饰品，再写轻微过曝、硬阴影、bloom、clipping、边缘泛光或斑驳光。
- 人脸进入近景时，要额外写底妆反射和高光范围；直闪优先提亮眼神、鼻梁窄线、唇部、发丝与服装边缘，额头大面和双颊不形成连续湿亮。
- 不要只写“氛围光、电影光、高级质感”；要写光线落在哪里、成像结果是什么。

### 【可以随机的变量】

- 本节只服务系列母版、详细提示词和抽卡关键词，不定义“同系列变体”的变化范围。
- 只随机不会破坏系列识别的层：动作细节、表情强度、镜头距离、前景遮挡、视线方向、选用道具、发丝和衣摆动势。
- 不随机主题、主场景、主光线、妆造方向和整体审美骨架。
- 系列图里每张只换 1-2 个变量，不要每张换一套世界观。
- 系列图里不同照片的动作、姿势、表情必须有差异；不要连续复用同一个靠杆、同一个手势、同一种冷脸或同一个回看角度。
- 写“变体”时不要沿用本节的小范围随机限制，改按“同系列变体必须编译为关键词链”执行。
- 可以随机的变量优先写成池：场景子空间池、服装同风格置换池、主道具池、动作表情池、镜头角度池、前景遮挡池、光线强度池。
- 抽卡关键词里，“可以随机的变量”不是附属模块，而是核心输出方式；变量池要短、清晰、可组合。

### 【负面约束词】

- 只写服务画面质量的负面约束，不写风险规避式改写。
- 默认包括：不要塑料皮肤、过度磨皮、过度锐化、HDR、廉价滤镜、绿幕感、端正商业摆拍、手指畸形、多余肢体、五官变形、头颈断裂、背景抢主体、元素堆砌成购物清单、风格互相冲突、额外文字水印。
- 负面约束要短，不要把整条 prompt 变成“不要清单”。

## 图片 / 组图关键词拆解规则

图片拆解的目标不是“这张图里有什么”的普通描述，而是把可见画面翻译成能复用、能扩展、能直接进入生图提示词的视觉语言。

### 拆解三层法

1. 事实层：只承认可见信息。看不清的内容标为“疑似”，不要补品牌、摄影师、相机型号、妆品色号或图片外故事。
2. 生成层：把事实翻译成 prompt-ready 关键词，例如把“闪光灯把脸打亮、背景发暗”翻译成 `CCD direct flash，机顶闪光，硬阴影，现场抓拍感`。
3. 变量层：区分固定锚点、可随机变量和偶发元素。固定锚点决定同款感；随机变量决定系列变化；偶发元素不要写进母版。

### 固定锚点怎么判断

固定锚点只保留真正影响图片识别度的内容，通常来自：

- 成像方式：胶片、CCD 直闪、柔雾棚拍、自然光中长焦、手机抓拍。
- 主视觉关系：人物与场景、人物与道具、光线与妆容、服装与空间是否共同成立。
- 人物妆造：脸型气质、妆容色彩、发型轮廓、皮肤质感。
- 服装结构：颜色、版型、材质和视觉重心。
- 光线结果：硬阴影、斑驳光、侧逆光、亮部 bloom、低对比柔雾。

不要把下面内容默认写成固定锚点：

- 单张图里碰巧出现的小物件。
- 背景角落的杂物、路人、墙上小字、临时反光。
- 看不清的饰品品牌、具体店名、精确相机参数。
- 只服务这一张构图的局部遮挡。

### 单图拆解

单图拆解按最终提示词模块输出，但每个模块写的是“可复用关键词”，不是长篇描述。

```text
【整体判断】：一句话说明这张图的写真方向和主要成立点。

【固定锚点】：列出这张图最应该保留的 3-6 个视觉锚点。

【比例】+【摄影器材】+【风格词】：画幅比例 + 推断出的成像方式 + 可复用风格词。不要硬编精确相机型号。

【五官/脸型】+【妆容】+【发型】：只提可见锚点；妆容按“底妆、眼妆、腮红 / 面中、唇妆、发型关系”压缩。

【穿搭】：只写服装本身，优先写版型、颜色、材质、层次和服装视觉重心。

【场景】：只写宏大空间、季节、天气、时代气质和空间氛围，不写具体道具。

【道具元素】：饰品 / 手持物 / 前景遮挡 / 桌面物 / 环境小物，用 `/` 分隔。结尾加“（道具根据实际构图需求选取，不要将所有的道具全都塞进一个画面中）”

【镜头角度】：视角、机位、景别、镜头距离和观看关系。

【构图】：主体位置、人物占比、前景遮挡、背景层次、裁切、留白、框中框、浅景深等画面组织方式。

【动作与表情】：自然语言描述这一瞬间的身体动作和表情，不写复杂人体难题。

【光线与质感】：按“来源 -> 落点 -> 结果”写光线；同时写皮肤、服装、道具和背景的材质反应。

【可以随机的变量】：后续生成同风格图时可以变化的动作、表情、镜头距离、前景遮挡、视线方向、选用道具。

【不建议固定的偶发元素】：只属于这张图、后续不必固定的细节。
```

### 组图拆解

组图拆解先看“重复出现的视觉机制”，不要先逐张罗列。共同骨架必须有多张图证据，或者是整组明显共享的成像逻辑。

先输出：

```text
【整体判断】：一句话说明这一组图的系列方向和主要成立点。

【系列共同视觉 DNA】：这一组共同成立的风格、成像、人物、妆造、服装、场景、光线和情绪骨架。

【系列变量池】：可以在同系列里变化的动作、镜头、构图、道具、表情、视线、景别和前景遮挡。

【单张差异变量】：
P01：这张图相对系列骨架变化了什么。
P02：这张图相对系列骨架变化了什么。
P03：这张图相对系列骨架变化了什么。
...
```

再按最终提示词模块整理整组可复用关键词：

```text
【固定锚点】：

【比例】+【摄影器材】+【风格词】：

【五官/脸型】+【妆容】+【发型】：

【穿搭】：

【场景】：

【道具元素】：

【镜头角度】：

【构图】：

【动作与表情】：

【光线与质感】：

【可以随机的变量】：

【不建议固定的偶发元素】：
```

组图判断规则：

- 多张稳定出现的内容，进入【系列共同视觉 DNA】或【固定锚点】。
- 每张不同的镜头、动作、表情、景别、选用道具，进入【单张差异变量】或【系列变量池】。
- 只出现一次且不影响系列识别的细节，进入【不建议固定的偶发元素】。
- 如果整组只有风格相似、但场景服装差异很大，就把共同点收窄到成像方式、光线和人物气质，不要强行写成统一场景系列。
- 从参考图生成变体时，不要把参考图中的动作、姿势、表情当作必须照抄的固定锚点；它们默认进入变量层，除非用户明确要求复刻某一张图的具体姿势。


用户要求继续生成完整提示词时，再把拆解结果转成最终提示词模板；没有明确要求时，只输出拆解结果。


抽卡关键词写作规则：

- 每行尽量短，优先关键词和变量池，不写长句解释。
- 一条抽卡关键词只保留一个主成像逻辑，例如 CCD、direct flash、35mm film、VHS、Pro-Mist 选一个。
- 场景和道具用池表达，但单张图只会随机选取一部分；不要写“必须全部出现”。
- 动作表情池要足够活，不要只写“自然、灵动、好看”。
- 负面约束只保留画质和结构问题，不要占据过多长度。

## 直接输出规则

- 按用户触发词输出系列母版、同系列变体关键词链、详细提示词或抽卡关键词，不输出“应该怎么写”的说明。
- 如果用户要求拆解关键词，输出关键词拆解结果，不默认继续生成完整提示词。
- 输出时必须把每个模块填成可直接生图的内容，不输出模板解释。
- 系列母版必须带 `【系列母版：主题名】` 标题，并在 `【动作与表情】` 下输出 P01-P08 或用户指定数量的分张任务。
- 同系列变体只用 `P01 / P02 / ...` 区分图片；每个 P 下输出一段无模块标题的完整关键词链。固定整体风格词链与固定成像机制词链必须在同组所有 prompt 中逐字一致。
- 详细提示词必须严格按模板模块输出，不额外增加“照片成立点”模块。
- 抽卡关键词必须短，保留变量池，不按详细模块展开。
- 默认中文；只有英文摄影词更准确时才保留英文。
- 不加入额外风险改写段。
- 不加入风险规避式造型语言，除非用户明确要求那种造型。
- 可以保留视觉负面约束，因为它服务图像质量。
- 如果用户要多条普通详细提示词，保持用户指定的共同骨架；如果用户明确说“变体”，只固定整体风格与成像机制，其他方面可根据当前系列的审美逻辑广泛变化。

## 快速填充示例

### 夏日果园胶片抓拍

成立点：场景 + 镜头。使用前景枝叶、青色果实、草帽、斑驳光、`35mm film photography`、低机位或藏在枝叶后的镜头感。

### 白兰奶油柔雾棚拍

成立点：光线 + 妆面。使用高调棚拍柔光、`Pro-Mist` 柔雾感、白色桌面、粉色兰花、清透奶油裸妆、低对比和轻微 highlight bloom。

### 黑板职感直闪写真

成立点：场景关系 + 成像方式。使用夜间办公室、白板公式、黑框眼镜、证件挂绳、桌沿、`direct flash`、硬阴影和自信近景构图。
